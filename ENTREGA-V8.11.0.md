# V8.11.0 — Entrega 4: Pulido visual integral

Aplicada únicamente sobre `/beta`.

## Cambios
- Sistema visual común mediante variables para colores, radios, sombras y espaciados.
- Encabezados más compactos y consistentes.
- Tarjetas unificadas en todos los módulos.
- Botones, estados hover, focus, disabled y pulsación normalizados.
- Campos y formularios con alturas, radios y foco consistentes.
- Modales y paneles con el mismo tratamiento visual.
- Navegación inferior refinada.
- Estados vacíos más compactos.
- Contadores y jerarquía tipográfica mejorados.
- Tabs, chips, badges y alineaciones normalizados.
- Animaciones discretas con soporte para `prefers-reduced-motion`.
- Ajustes específicos para celular.
- Caché PWA y versión actualizadas.
