# AUDIT v12.3.0.1

## Tareas compartidas por sector

- Se eliminó el filtro que ocultaba al personal las tareas asignadas a otros responsables.
- Todo usuario activo con el módulo Tareas ve las tareas del sector asociado a su cuenta.
- Las tarjetas continúan agrupadas por responsable.
- Personal: solo puede completar; no puede asignar, editar ni eliminar.
- Supervisor y administrador conservan las acciones administrativas.
- Cualquier usuario del sector puede completar una tarea, incluida una cuenta genérica de celular compartido.
- La autorización del endpoint de completado valida el sector, no el responsable original.
- El horario sigue utilizándose únicamente para las notificaciones.
