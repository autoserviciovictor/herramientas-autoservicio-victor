# V8.8.0 Beta — Entrega 1: Identidad visual

- Se reemplazaron los emojis visibles por iconos SVG profesionales y consistentes.
- El campo de contraseña usa ojo abierto y ojo tachado.
- Se unificaron los iconos del menú principal, login, menú de usuario, botones y estados vacíos.
- Las seis tarjetas del menú principal usan fondo blanco.
- Se eliminó el fondo rojo particular del icono de Administración.
- Se regeneraron los iconos PWA con fondo rojo completo para evitar el efecto de figura dentro de otro cuadrado.
- Se actualizó la versión de caché del service worker.

Los cambios fueron aplicados exclusivamente en la carpeta `/beta`.
