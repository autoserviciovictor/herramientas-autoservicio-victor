# Auditoría v11.3.2

## Cambios

- Se igualó la tipografía, peso, iconos y espaciado del menú lateral de Inventario con el App Shell compartido.
- Se simplificó el editor de usuarios eliminando bordes, tarjetas internas y divisores innecesarios.
- Se conservaron bordes únicamente en campos y selectores editables.
- La grilla de módulos visibles quedó centrada y uniforme en escritorio y móvil.
- Se alinearon checkbox, icono y nombre de cada módulo.
- Se mantuvieron fijas las acciones inferiores del modal.
- Se conservó el hotfix del servidor: `invalidarCache("usuarios")` y versión correcta del backend.
- Se renovó el caché PWA y se actualizaron referencias a `v=1132`.
